01이게 뭔가요

맵에 유닛을 원·별·꽃 모양으로 뿌릴 때 쓰는 좌표 도형을 다루는 웹 도구입니다. 세 가지를 합쳐 놨습니다.

  • 아틀라스 — 44TRIG 135개, 마린키우기 4vs4 428개, 모두 563개 도형(좌표점 36,285개)을 눈으로 훑어보고 좌표를 그대로 가져다 씁니다.
  • 제작 작업대 — CB Paint v2.5의 CS 함수를 JS로 옮겨 놨습니다. 생성기 22종 · 연산 38종 · 합치기 5종을 폼으로 조립하면 결과가 실시간으로 그려집니다.
  • 점 편집기 — 계산 결과를 점 목록으로 굽고, 격자 위에서 점을 하나씩 찍고 끌어서 고칩니다.

결과는 CB Paint에 그대로 붙여 넣으면 도는 Lua 코드로 나옵니다. 작업대에서 보이는 모양이 곧 인게임에서 그 Lua 식을 돌린 결과입니다 — 같은 함수를 같은 순서로 계산하기 때문입니다.

06작업대 기본 흐름

작업대는 위에서 아래로 흐릅니다.

  1. 레이어를 쌓습니다. 왼쪽 위에서 종류를 고르고 ＋ 레이어를 누릅니다.
  2. 레이어마다 연산을 겁니다. 회전·대칭·오려내기 같은 CS_ 함수를 위에서 아래 순서로 적용합니다.
  3. 레이어끼리 합칩니다. 두 번째 레이어부터 “합치는 법”이 붙습니다. 위에서 아래로 차례차례 합쳐집니다.
  4. 결과에 후처리를 겁니다. 합쳐진 전체에 연산을 한 번 더 겁니다.
  5. 이름을 적고 저장하거나, Lua를 복사합니다.

오른쪽 미리보기와 Lua 코드는 값을 바꿀 때마다 즉시 다시 계산됩니다. 레이어마다 ◉ 끄기로 잠깐 빼 보거나, ⧉로 복제할 수 있습니다.

되돌리기가 있습니다. 레이어 줄 오른쪽 ↶ ↷ 버튼, 또는 Ctrl+Z / Ctrl+Shift+Z. 작업대 상태는 브라우저에 자동 저장돼서 창을 닫았다 열어도 그대로입니다.

Lv 칸 — 겹 수로 점 개수 정하기

정다각형·원·별 계열에는 Number(점 개수)와 Hollow(안쪽부터 비울 개수) 옆에 Lv 칸이 있습니다. 여기에 겹 수를 넣으면 점 개수를 대신 계산해 줍니다.

  • 정육각형 Lv 3 → 가운데 1점 + 1겹 6점 + 2겹 12점 = 19점
  • Hollow의 Lv를 2로 주면 안쪽 2겹을 비워 테두리만 남습니다.

내보낸 코드에도 숫자가 아니라 CS_Level("Polygon", 6, 3) 으로 나가서, 나중에 겹 수만 바꾸기 쉽습니다.

채우기 인자

  • 범위는 최소 / 최대 두 칸입니다. -96 ~ 96 이면 192px 폭입니다.
  • Edge가 “가장자리 포함”이면 양 끝 선 위에도 점이 놓입니다.
  • 벌집 채우기는 줄마다 반 칸씩 밀어 육각 배열을 만듭니다. 유닛이 덜 겹칩니다.
  • 무작위 채우기의 “겹침 X·Y”는 이 거리 안에는 다른 점을 두지 않으려고 100번까지 다시 뽑는다는 뜻입니다.

09수식 자리와 곡선 94종

그래프·극좌표·매개변수 생성기와 벡터 변환·식으로 오려내기 연산에는 식을 적는 칸이 있습니다. 뭘 적어야 할지 모를 때 쓰라고 칸마다 두 가지를 붙여 놨습니다.

  • 고르기 드롭다운 — 곡선을 고르면 식뿐 아니라 Start · StepSize · StepRange · Number 까지 그 곡선에 맞게 같이 바뀝니다. 고른 즉시 그려지니 숫자만 만지면서 다듬으면 됩니다.
  • ? 버튼 — 그 자리에서 쓸 수 있는 값, 돌려줘야 하는 값, 쓸 수 있는 math 함수, 그리고 그 자리의 식 전부를 표로 보여줍니다.

직접 쓸 때

숫자와 + - * / % ^, 괄호, { } 로 묶은 두 값을 쓸 수 있습니다. 함수는 math.sin cos tan asin acos atan sqrt abs exp log floor ceil max min fmod random 과 상수 math.pi 입니다.

각도는 전부 라디안입니다. 도(°)로 넣고 싶으면 math.rad(30) 처럼 바꿔 쓰세요. 그리고 도형이 안 닫히면 Number를 늘리세요 — 그래프 생성기는 “StepSize 만큼 Number 번 걸어간다”는 방식이라, 곱한 값이 곡선 길이보다 짧으면 중간에서 끊깁니다.

자주 쓰는 것

  • 만화경 — 조각 하나만 그려 놓고 Point를 6으로 주면 6방향 대칭 도형이 완성됩니다. 눈 결정·문양을 만들 때 가장 빠릅니다.
  • 도형으로 오려내기 — 기준이 될 도형을 목록에서 고릅니다. 그 도형이 그리는 테두리 안(또는 밖)에 있는 점만 남습니다. 채우기 + 오려내기 조합이 “별 안을 유닛으로 채우기”의 정석입니다.
  • 정렬 · 순서 뒤집기 — 유닛이 생성되는 순서를 바꿉니다. 바깥에서 안으로 조여드는 연출을 만들 때 정렬 R 을 씁니다.
  • 겹친 점 제거 — Size 안에 겹친 점을 하나만 남깁니다. 유닛이 같은 자리에 쌓이는 걸 막습니다.

  • 중심을 원점으로 — 도형 한가운데를 (0,0)으로 옮깁니다. 회전·대칭을 걸기 전에 눌러 두면 결과가 예상대로 나옵니다.
  • 전부 격자에 — 이미 찍힌 점을 전부 격자 배수로 반올림합니다.
  • 화면 맞춤 — 도형 전체가 보이도록 축척을 다시 잡습니다.

오른쪽 좌표표에서 줄을 눌러도 점이 골라집니다. 다 고쳤으면 적용(레이어에 반영) 또는 새 도형으로 저장을 누릅니다.

13Lua 코드 내보내기

미리보기 아래 Lua 코드 상자에 항상 최신 코드가 들어 있습니다. Lua 복사를 누르면 클립보드로 갑니다. 이름 칸에 적은 이름이 변수명이 됩니다(안 적으면 MyShape).

function MyShape_f1(t) return {96*math.cos(t)^3, 96*math.sin(t)^3} end

local L1 = CS_Kaleidoscope(CSMakeStar(5, 120, 32, 0, CS_Level("Star", 5, 3), 0), 6, 0, 0, 0)
local L2 = CSMakeGraphT(1, "MyShape_f1", 0, 0, 6, 0.078, 97)
local R = CS_Overlap(L1, L2)
R = CS_FixShape(R) -- 극좌표 연산에서 원점이 nan 이 되는 것 방지
MyShape = R

세 가지를 알아서 처리합니다.

  • 식을 적은 칸은 CB Paint 규칙대로 이름 있는 전역 함수(MyShape_f1)로 뽑아서 위에 올려 줍니다. 그래야 CSMakeGraphT 가 이름으로 찾아 씁니다.
  • Lv 칸을 쓴 자리는 숫자 대신 CS_Level(…) 로 나갑니다.
  • 극좌표 연산을 하나라도 썼으면 마지막에 CS_FixShape 를 붙입니다 — 원점 (0,0)에 극좌표 계산을 하면 atan(0/0) 이 nan 이 되기 때문입니다.

14새 도형 직접 추가

아틀라스 위쪽 ＋ 새 도형 버튼입니다. 세 가지 방식이 있고, 옆에서 바로 미리보기가 그려집니다.

방식넣는 것
Lua 식한 줄짜리 CS 식. 아틀라스 도형 이름을 변수처럼 그대로 쓸 수 있습니다 — CS_Rotate(SHA49a, 45)
Lua 스크립트여러 줄. local A = … 대입과 function f(x) return … end 한 줄짜리 함수를 읽습니다. 마지막 값이 결과입니다. 맵 소스의 CS 코드를 그대로 붙여 넣어 보세요.
좌표 붙여넣기숫자만 뽑아 두 개씩 짝지어 읽습니다. {n,{x,y},…} · {{x,y},…} · 한 줄에 x, y 모두 됩니다.
 
-- Lua 스크립트 예시
function fr(a) return 72 + 28*math.cos(6*a) end
local F = CSMakeGraphA(1, "fr", 0, 0, 10, 0.4, 72)
F = CS_Rotate(F, 15)
F

제어문(if·for)과 여러 줄짜리 함수는 아직 못 읽습니다.

15저장·백업과 한계

내가 만든 도형은 어디에 남나

공개 링크로 여는 판은 지금 쓰는 브라우저에만 저장됩니다. 서버로 올라가지 않으니 다른 사람에게는 보이지 않고, 브라우저 데이터를 지우거나 다른 기기에서 열면 없습니다. 내장 도형 563개는 페이지 자체에 들어 있어 누가 열어도 그대로 보입니다.

그래서 백업 버튼이 있습니다. 내보내기를 누르면 내 도형 전체가 JSON 한 덩어리로 나오고, 그 글자를 다른 곳에 붙여 두면 됩니다. 되살릴 때는 그 JSON을 다시 붙여 넣고 합쳐서 불러오기 또는 덮어쓰기를 누릅니다. 이름이 겹치면 뒤에 번호를 붙여 줍니다.

페이지가 스스로 파일을 내려받게 하는 건 막혀 있습니다. 백업이 파일이 아니라 글자 복사·붙여넣기인 건 그 때문입니다. 시크릿 모드에서는 저장 자체가 막히니, 그때는 작업 중간중간 JSON을 복사해 두세요.

16따라 해보기

① 꽃 모양 30초 만에 만들기

  1. 작업대 → 종류를 CS 생성기 → ＋ 레이어
  2. 생성기를 극좌표 r = f(a) 로 바꿉니다.
  3. 식 칸 옆 고르기 → 꽃잎 6장
  4. 이름을 적고 저장, 또는 Lua 복사

② 별 안쪽을 유닛으로 채우기

  1. 먼저 별을 만들어 둡니다 — CS 생성기 → 별, Point 5, Radius 112, Number 11, Hollow 0. 이름을 SHStar 로 저장합니다.
  2. 작업대를 비우고 새 레이어 CS 생성기 → 격자 채우기 XY. 범위 -112 ~ 112, 간격 14.
  3. 그 레이어에 연산 도형으로 오려내기 를 추가하고, 기준 도형으로 SHStar 를 고릅니다.

별 테두리 안쪽에 있는 점만 남습니다. 기준 도형을 바꾸면 같은 채우기를 다른 모양으로 오려낼 수 있습니다.

③ 있는 도형 비틀어 새로 만들기

  1. 아틀라스에서 마음에 드는 도형을 열고 작업대에 추가
  2. 연산 벡터 변환 RA 추가 → 고르기 → 소용돌이
  3. a + r/400 의 400을 줄일수록 세게 감깁니다.

④ 눈 결정 만들기

  1. CS 생성기 → 그래프 y = f(x) → 고르기 포물선
  2. 연산 이동 XY 로 Y 를 −48 만큼 옮겨 원점에서 띄웁니다.
  3. 연산 만화경, Point 6

⑤ 손으로 찍은 로고 다듬기

  1. 종류를 직접 찍기 → ＋ 레이어 (점 편집기가 바로 열립니다)
  2. 격자 를 16으로 두고 왼쪽 절반만 찍습니다.
  3. 적용 후 연산 거울 X 를 걸면 오른쪽이 자동으로 만들어집니다.
