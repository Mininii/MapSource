# 마린키우기 서리선 원정 1.0

실행 파일: 저장소 루트의 `마린키우기_서리선원정_128x128_v1.0.scx`.

StarCraft Remastered의 `Maps` 폴더 아래에 복사하고 **Use Map Settings / 유즈맵 설정**으로 방을 만듭니다. 인간 슬롯 P1~P5 중 1~5개를 사용하세요. P6~P8은 컴퓨터입니다. P1 없이도 시작할 수 있습니다.

## 새 맵의 구성

원본 `마린키우기_쥬림산맥_2.8_공2배_리밸런싱F4.scx`를 분석한 후, 사냥·보상·병력 성장·거점 돌파라는 장르 구조를 새로 구현했습니다. 원본의 크기는 256×256, 유닛 2,174개, 트리거 1,663개입니다. 원본 제작 표기인 픽시브 / 스나이퍼광은 새 맵 설명에도 남겼습니다. 원본의 공식 후속작이라는 의미는 아닙니다.

새 맵은 128×128 Arctic 타일셋에 신규 경로·기지·상점·적 배치를 구성하고 일반 트리거 202개로 진행합니다. 원본의 기본 CHK 헤더와 VCOD, 평지 타일 쌍을 재사용했습니다. 원본 게임 트리거, EUD 메모리 조작, 외부 음악은 새 맵에 넣지 않았습니다. 평지 타일 쌍은 Jungle/Arctic의 공통 지형 계열을 이용하며, 원본 지형 전체를 축소한 것이 아닙니다.

- 시작: 마린 4명, 의무관 1명, 보급관 1명, 광물 650.
- 성장: 처치·건물 파괴 점수 100당 광물 35 자동 환전. 100 미만 잔여 점수는 보존됩니다. 환전 점수는 별도 공헌 점수에 누적합니다.
- 공헌 보상: 1,000 / 5,000 / 15,000점 달성 시 광물 300 / 700 / 1,500.
- 정기 보급: 약 10게임초마다 광물 25.
- 남쪽 개인 엔지니어링 베이: 보병 공격·방어 각각 최대 30단계. 첫 연구 광물 100, 이후 단계마다 비용 60 증가, 가스 불필요. 상위 연구의 선행 조건을 위해 개인 사이언스 퍼실리티도 배치했습니다. 마린 사거리와 스팀팩은 처음부터 사용 가능합니다.
- 전초기지 회복 구역: 마린·정예마린·의무관 체력, 의무관 에너지 자동 회복.
- 재정비: 마린과 정예마린이 모두 없어지면 약 12게임초 뒤 마린 3명·의무관 1명으로 복구. 정예마린은 복구하지 않습니다.
- 목표: 백야 군락 → 동상 군락 → 영구동토 군락 순서로 파괴하고 서리왕을 처치합니다. 다음 군락은 이전 군락 파괴 시 무적이 풀립니다.
- 군락 보상: 각 참가자에게 광물 600 / 800 / 1,000.
- 난도: 군락·보스 시작 체력은 1~5인에 따라 36 / 52 / 68 / 84 / 100%. 공세 병력 수도 시작 인원에 따라 증가합니다. 도중 이탈 시 재조정하지 않습니다.
- 공세: 약 60게임초 뒤 시작, 이후 약 30게임초 간격. 사냥터 병력은 상한 내에서 보충됩니다.
- 패배: 동력로 파괴. 동력로와 보스가 같은 판정 주기에 파괴되면 패배를 우선합니다.

시간은 기본 트리거 주기 기준 근사값입니다. Fastest에서는 실제 초보다 빠르게 진행됩니다.

## 보급관 상점

시민 모양의 **보급관**을 남쪽 프로토스 신호소에 이동시키면 구매하고 대기 위치로 돌아옵니다. 충원 병력은 자신의 전초기지 집결지에 등장합니다. 자원 부족이나 보유 상한에서는 결제하지 않습니다.

| 남쪽 신호소: 왼쪽부터 | 광물 | 개인 상한 |
| --- | ---: | ---: |
| 마린 | 250 | 12 |
| 의무관 | 200 | 3 |
| 정예마린 | 2,000 | 2 |
| 모든 전투 병력 귀환 | 100 | 해당 없음 |

마린 체력 360 / 기본 공격력 24(+4), 정예마린 체력 1,800 / 기본 공격력 84(+8), 의무관 체력 300입니다. 정예마린은 구매 즉시 별도 영웅 유닛으로 합류합니다.

## 파일과 수정

- `build.py`: 원본 SCX에서 필요한 기반 데이터를 읽고 새 SCX를 생성합니다.
- `scenario.chk`: 보호·압축 페이로드를 붙이지 않은 편집용 CHK.
- `verify.py`: 구조 검사 및 실제 생성된 트리거 바이트코드의 제한된 모의 실행.
- `validation.json`: 검사 결과와 검사하지 못한 항목.
- `manifest.json`: 배치·로케이션·트리거 목록과 파일 해시.
- `preview.html`, `tactical-preview.svg`: 전술 배치도. 게임 화면 캡처가 아닙니다.
- `preview.py`: 전술 배치도 재생성.

현재 환경에서 재빌드:

```bash
/home/developer/.eudplib-linux/venv/bin/python NewMaps/Frostline/build.py
/home/developer/.eudplib-linux/venv/bin/python NewMaps/Frostline/verify.py
python3 NewMaps/Frostline/preview.py
```

Python 의존성은 eudplib 0.80.6의 MPQ API와 일반 트리거 직렬화기입니다. 게임 실행에는 eudplib이 필요하지 않습니다. `build.py`는 위 이름의 출력 파일을 교체하므로 에디터로 직접 수정한 출력은 별도 이름으로 보존하세요. 원본 F4 파일은 읽기만 합니다. ISOM은 생략하고 MTXM/TILE을 기록했으므로 지형은 사각 타일 방식으로 다룹니다.

## 검증 범위

MPQ에서 scenario.chk를 다시 추출하여 원본 생성 데이터와 일치함을 확인했습니다. 섹션 길이·좌표·문자열 참조, 설계상 통로 연결, 일반 트리거 조건/행동을 검사했습니다. 트리거 바이트코드 모의 실행은 빈 슬롯, P1 없는 시작, 중복 결제, 자원 부족, 병력 상한, 환전 나머지, 재정비, 군락/보스 진행, 승패 우선순위, 공세 누적 상한, 귀환을 확인합니다.

**StarCraft Remastered와 SCMDraft를 실제 실행한 검증은 하지 못했습니다.** 게임의 CV5/VF4 기반 통행 판정, 지형 경계 렌더링, 적 AI·전투 결과·UI와 실제 난도는 모의 실행 범위 밖입니다. 게임 플레이 테스트가 끝난 밸런스 확정판으로 보아서는 안 됩니다.
